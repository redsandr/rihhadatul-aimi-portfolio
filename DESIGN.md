# Visual system

Near-black, warm ivory, pale chartreuse, and clay coral set the palette. Space Grotesk handles headings and navigation; Instrument Serif marks the occasional change of voice; DM Sans carries paragraphs. The hero plays the owner's character film on desktop. The 3D gallery holds local renders and images from two published ArtStation projects. The RAG page includes a real screenshot from its repository. The project diagrams are CSS, not screenshots of software that doesn't exist.

GSAP handles the hero entrance and parallax. Motion handles scroll-linked text and image changes. The mobile menu opens as a full-screen sheet; its links enter in sequence. The RAG and CogniFi case pages each have a large, four-step animation that readers can pause or control directly. The gallery changes images every 5.2 seconds while visible, then stops when someone chooses a picture. Reduced-motion settings disable the autoplay and CSS loops. The video stays paused on mobile until tapped. Keyboard focus remains visible, and arrow keys change images in the artwork panel.
